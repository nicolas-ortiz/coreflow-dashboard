# Coreflow Dashboard

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Prisma + SQLite (local)

## Run
npm run dev

## Database
- Prisma schema: prisma/schema.prisma
- SQLite local file (not committed)

## Conventions
- Minimalist UI
- Neutral colors
- Server Components by default
- API routes in src/app/api

## Features
- Tickets
- Payments
- Clients
- Excel export by date range
